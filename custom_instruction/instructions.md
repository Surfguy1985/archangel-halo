# Always-On Design, Experience & Architecture Standards

When working on any UI or product experience in this project:

1. Read and strictly follow the skill at `.agents/skills/premium-ui-ux-fixer/`.
2. Prefer elevating the existing design system and tokens rather than inventing one-off styles.
3. Every visual change must move the product toward premium, high-taste aesthetics (Klarna / Stripe / Linear level).
4. Never introduce AI-slop patterns (generic Inter + purple gradients, nested identical cards, weak hierarchy, harsh pure black/white).
5. Always maintain accessibility (contrast, focus states, reduced motion) and consistent spacing on an 8px grid.
6. Glow effects must be soft, brand-colored, and purposeful — never decorative neon.
7. When elevating experience or flows, research top industry products that do similar things and apply their best principles.
8. When the component system or architecture is weak, actively look for high-quality open-source design system or architectural repos and adapt the strongest patterns into this project.

If the user asks to fix/improve/polish the UI, elevate the experience, improve flows, or pull from design/architectural repos, fully activate the premium-ui-ux-fixer skill and run its complete process.
