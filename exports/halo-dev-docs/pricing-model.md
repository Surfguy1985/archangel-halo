# HALO API Platform — User-Tier Pricing Model

## Executive Summary

### Model principle

HALO charges a core platform fee in 50-user bands, then adds only the selected business Legos. API consumption is metered separately so high-usage partners remain profitable. Accounts above 1,000 active users or 50 million monthly API calls move to a negotiated enterprise agreement.

| Standard pricing range | 1-1,000 monthly active users | RECOMMENDED COMMERCIAL PACKAGES |
|---|---|---|
| Tier interval | 50 active users | Package |
| Core platform range | $995-$6,250 per month | Business Essentials |
| Included API allowance | 5,000 calls per maximum tier user | Operations Suite |
| Module pricing | Per active user, volume-discounted | Full Business OS |
| Enterprise threshold | >1,000 users, >50M calls or >250 sustained RPS |  |

Why this model works

Predictable — Partners know their monthly platform cost before usage overages.

Composable — Every module can be purchased, embedded and removed independently.

Scalable — Per-user module rates decline as adoption grows.

Protected — Heavy API and infrastructure users automatically move to enterprise review.

Internal recommendation: UR Founders should package HALO as recurring customer value, not expose wholesale pricing. Use the Calculator tab to set a retail markup and estimate gross margin.

## Enterprise Pricing

Custom Enterprise Pricing Framework

### Automatic enterprise review triggers

1 — More than 1,000 monthly active users

2 — More than 50 million API calls per month

3 — Sustained throughput above 250 requests per second

4 — Dedicated environment, region or data residency

5 — 99.95% or higher contractual SLA

6 — Custom compliance, security or audit requirements

7 — 24/7 support or named technical account management

### Negotiated commercial components

| Annual platform commitment | $75,000-$250,000+ | Minimum annual contract value based on scale and complexity. |
|---|---|---|
| Monthly active user rate | $2-$6 per MAU | Graduated or committed volume pricing. |
| API consumption | $0.08-$0.35 per 1,000 calls | Based on committed monthly volume and workload profile. |
| Dedicated environment | $3,000-$15,000 per month | Dedicated compute, database, networking or region. |
| Implementation | $25,000-$250,000 one time | Migration, SSO, integrations, security review and custom modules. |
| Premium support and SLA | 10%-20% of annual contract value | Named TAM, 24/7 support, response times and service credits. |
| Security / compliance package | $15,000-$100,000 per year | Audit support, custom controls, data residency and compliance commitments. |
| Contract term | 12-36 months | Use minimum commitments and true-up provisions. |

Enterprise rule: never quote solely from user count. Price from the higher of committed users, API volume, infrastructure cost, support burden, compliance obligations and strategic value. Add a minimum annual commitment and pass through all third-party regulated-service costs.

## Definitions

Billing Definitions and Guardrails

| Term | Definition | Billing Treatment | Guardrail |
|---|---|---|---|
| Monthly Active User (MAU) | A unique end user who authenticates or performs a billable action during the calendar month. | Counted once per partner per month. | Service accounts are excluded but their API calls are metered. |
| User tier | The 50-user band containing the month's MAU count. | Monthly fee is based on the highest MAU count reached in the billing month. | Use daily unique-user snapshots to prevent manipulation. |
| API call | A successful or billable request to a HALO API, embedded component backend or webhook delivery. | Deducted from included allowance, then billed as overage. | Authentication failures and HALO-caused 5xx errors are excluded. |
| Active module user | An MAU entitled to or using a selected module. | Default is all partner MAUs unless entitlement is scoped to a subset. | Module usage should be auditable by entitlement. |
| Third-party cost | Banking, payment, tax filing, payroll, messaging, model or other provider charge. | Passed through plus contracted service fee. | Do not bury volatile regulated-provider cost inside fixed pricing. |
| Professional service | Bookkeeping, tax preparation, legal, advisory, implementation or managed operations. | Priced separately from software. | Maintain separate order forms and scope of work. |
| Enterprise customer | A customer meeting a scale, API, infrastructure, support, compliance or SLA trigger. | Custom annual agreement. | Minimum annual commitment, true-ups and pass-through costs required. |
